## Educational

Inputs: topic = running better 1:1s; audience = first-time managers.

```
NEVER run a pointless 1:1 again.

I've run 600+ of them as an engineering manager. These 6 rules fixed mine:

1. They own the agenda, not you
→ Shared doc, they add topics 24h before. Empty doc = reschedule.

2. Start with "What's on your mind?"
→ Not "Status update?" Status goes in Slack.

3. Ask one career question every time
→ "What's one skill you want to get better at this month?"

4. Write down every commitment you make
→ Review the list at the start of the next 1:1.

5. Never cancel. Move it.
→ Canceling says "you're not a priority." They notice.

6. End with "What could I do better?"
→ Awkward the first 3 times. Gold after that.

Which one are you skipping?

Comment "1:1" and I'll send you my agenda template.
```
